About This Project

Comprehensive Analysis of TV Energy Consumption

🎯 Project Objectives & Target Audience

This data visualization project aims to empower average Australian consumers with actionable insights into television energy consumption. By analyzing the current market, it helps buyers balance screen size and technology with long-term electricity costs.

Secondary audiences include electronics retailers and environmental policymakers looking to understand market trends in appliance efficiency.

📊 Data Source & Methodology

The dataset is publicly sourced from the Australian Government's Appliance Energy Rating database. The raw data was extensive and required significant preprocessing in KNIME to ensure accuracy:

  • Data Cleaning: Handled missing values and standardized brand names (e.g., merging "Samsung" and "Samsung Electronics") using String Cleaner and String Replacer.
  • Data Transformation: Converted screen sizes from centimeters to inches and categorized them into "Small", "Medium", and "Large" segments using the Expression node.
  • Aggregation: Utilized the Pivot and GroupBy nodes to calculate the mean energy consumption across different screen technologies.

💻 Technical Stack

  • Data Pipeline: KNIME Analytics Platform (Workflow automation).
  • Frontend Web: HTML5, CSS3, Vanilla JavaScript (DOM manipulation, Event Listeners).
  • Version Control: Git & GitHub.
